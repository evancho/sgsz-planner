# 三國志戰略版配將簿

離線優先的繁體中文小工具，用來記錄**多個帳號**的武將、戰法與隊伍。資料只存在這台裝置的瀏覽器，不會上傳，也沒有自動同步。

線上版：<https://evancho.github.io/sgsz-planner/>

若這個網址還沒開，到倉庫 **Settings → Pages**，Build and deployment 選 **Deploy from a branch**，分支選 `main`、資料夾選 `/ (root)`，再按 Save。程式已經在 `main`。

## 加到 iPhone 主畫面

1. 用 **Safari** 打開上面的網址（Chrome 的「加入主畫面」不一定能離線）。
2. 點下方的**分享**。
3. 往下滑，點**加入主畫面**。
4. 主畫面會出現「配將簿」。第一次需要有網路，讓它把圖鑑存下來；之後沒網路也能開。

Android 可用 Chrome 的「加到主畫面」。電腦直接用瀏覽器即可。

## 多帳號

- 右上角選單可以切換帳號。
- 「帳號」頁可以新增、改名、刪除。
- 每個帳號各自擁有：武將紅度、動態形象、覺醒、戰法、自訂戰法、隊伍。
- 換帳號不會把另一個帳號的隊伍帶過去。

至少會留一個帳號。刪除前請先匯出備份。

## 備份與還原

1. 打開**備份**。
2. **下載 JSON**，或全選文字複製，存到雲端硬碟、檔案 App 或另一台電腦。
3. 換手機或清掉網站資料之後，用**選擇檔案**或把 JSON 貼上，再按**從文字匯入**。
4. 確認帳號名稱後，選擇**取代並還原**。這會蓋掉這台裝置上目前的全部帳號。

備份檔包含所有帳號，不是只有正在看的那一個。

## 怎麼用

**武將**只收名將（橙卡），列表一行一位，名稱是武將本名（孫尚香、陸遜、周瑜），不會在名字前面加「典藏」。勾選擁有後可展開紅度 0–5、動態形象、覺醒；設定其中一項就會收合，並立刻寫進這台裝置。再點名稱可以展開改下一項。取消擁有也會收合。有動態形象或可覺醒的卡，才會出現「有／無」；內政武將不顯示覺醒。把動態形象標成「有」之後，列上才會出現「典藏」。篩選對齊遊戲裡常見的條件：品質、適性 A 以上、陣營、COST、軍事／內政、典藏、動態形象。預設依統御由高到低，同統御再依魏、蜀、吳、群；篩選之後仍是這個順序。也可以改成稀有、統御由低到高、陣營或名稱。新帳號的武將與戰法都是未擁有，只有按「載入範例配隊」才會勾上範例。已經上陣的卡會在名字下方標「部隊中」。自帶戰法有資料才顯示，沒有就不留空的「自帶戰法」。

**戰法**收已核對的 S 級與 A 級。每一列有等級標籤。列表先排 S，同等級再依類型、名稱。類型分頁：全部、指揮、主動、突擊、被動、兵種、陣法、內政。可搜尋名稱或說明。同一戰法同時只能裝在一個位置；裝上之後列表會變成灰色的**已佔用**，可配置從 `1/1` 變成 `0/1`。底部的**事件**、**戰法傳承**是入口：事件用來對事件戰法做記號，傳承用來對照常見來源。兩者都只寫進這個帳號，不會真的消耗武將。更低階的戰法用「新增非橙戰法」手動加入。

**隊伍**可以有多支，各有名稱與備註，三個位置由左到右是副將、主將、副將。每位武將有鎖定的主戰法（自帶；圖鑑沒填就不顯示），加上兩個傳承槽。兵書先選體系（作戰、虛實、軍形、九變、始計、用間），再選主兵書與副兵書。同名武將不能同時上陣。一隊只能有一個陣法。內政戰法只能配內政武將。這個版本沒有裝備，也沒有敵軍。

「帳號」頁的**載入範例配隊**會寫入一套桃園盾，方便先看介面。它會改掉該帳號原本的擁有狀態與隊伍。

## 擴充圖鑑

圖鑑版本寫在 `data/meta.json` 的 `catalogVersion`（目前 1.2.1）。武將名冊是常見卡，**故意沒有收全**。戰法的戰鬥類 S 級收到兗州之戰的公開清冊，並補上已核對的後續事件戰法；A 級只收已核對類型的常用戰法，沒有把每張紫將都收進來。英雄命示的十二都尉以陣營「群」、標籤「都尉」收入，統御記 7（天賦身經百戰可 +1），適性暫以全 A 佔位。同賽季商店的拓本與精進陣法另列，來源標成「賽季」，不覆蓋原戰法。自帶戰法只填了較確定的幾張，沒填的列上不顯示自帶那一行。`collection` 固定為 `false`：典藏是帳號把動態形象標成「有」之後才出現，不是另一張卡。改 `scripts/tactic-catalog.mjs` 後執行 `node scripts/build-catalog.mjs`，它會覆寫 `data` 底下的 JSON。

`data/generals.json` 一筆長這樣：

```json
{
  "id": "guanyu",
  "name": "關羽",
  "camp": "蜀",
  "cost": 7,
  "role": "軍事",
  "quality": "名將",
  "collection": false,
  "dynamic": true,
  "awaken": true,
  "apt": { "騎": "S", "盾": "A", "弓": "C", "槍": "S", "器械": "C" },
  "innate": "威震華夏",
  "nameKey": "關羽"
}
```

`dynamic: false` 表示沒有動態形象可解鎖，畫面上會隱藏該列。`awaken: false` 同樣會隱藏覺醒。`nameKey` 用來擋同名上陣。`data/tactics.json` 用 `rank`（`S` 或 `A`）、`source`（`傳承` 或 `事件`）、`from`（武將 id）、`troops`（兵種限制，`null` 表示通用）。`data/bingshu.json` 是六個兵書體系，每系有主兵書與副兵書。

三份 JSON 的 `catalogVersion` 請一起改。`scripts/build-catalog.mjs` 會**覆寫**這三份檔案，只有想整批重產時才執行 `node scripts/build-catalog.mjs`。

## 更新

App 開著的時候如果 GitHub Pages 有新版本，上方會出現「有新版本可用」。點「重新載入」才會換上，不會自己重整。

確認方式：這版先開過一次，再把 `sw.js` 裡的 `CACHE` 改成新名稱並部署。回到這個分頁（或主畫面 App）就會看到提示；點下去之後提示消失，也不會一直重複跳出。

## 開發

靜態檔，沒有建置步驟。在這個資料夾執行：

```bash
python3 -m http.server 8765
```

然後打開 `http://127.0.0.1:8765/`。不要用 `file://`，否則圖鑑與離線快取不會載入。

```bash
npm test
```

檢查篩選、佔用、同名、備份格式與圖鑑是否對得起來。
