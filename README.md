# 三國志戰略版配將簿

離線優先的繁體中文小工具，用來記錄**多個帳號**的武將、戰法與隊伍。資料只存在這台裝置的瀏覽器，不會上傳，也沒有自動同步。

線上版：<https://evancho.github.io/sgsz-planner/>

若這個網址還沒開，到倉庫 **Settings → Pages**，Build and deployment 選 **Deploy from a branch**，分支選 `main`、資料夾選 `/ (root)`，再按 Save。程式已經在 `main`。

## 加到 iPhone 主畫面

1. 用 **Safari** 打開上面的網址（Chrome 的「加入主畫面」不一定能離線）。
2. 點下方的**分享**。
3. 往下滑，點**加入主畫面**。
4. 主畫面會出現「配將簿」。第一次需要有網路，讓它把圖鑑存下來；之後沒網路也能開。

Android 可用 Chrome 的「加到主畫面」。電腦直接用瀏覽器即可。

## 多帳號

- 右上角選單可以切換帳號。帳號頁每張卡的左右箭頭可調整順序，選單與備份都依這個順序。
- 「帳號」頁可以新增、改名、刪除。每張帳號卡也可以匯出這個帳號，或載入一份單帳號檔。
- 載入時先確認內容，再選擇新增為新帳號，或覆寫目前這張。覆寫前會再問一次，避免蓋掉武將、戰法與隊伍。
- 新賽季用「新增為新帳號，不含隊伍」：武將與戰法進新帳號，舊隊伍不帶過去。匯出時可勾「不含隊伍」。整包備份仍包含隊伍。
- 每個帳號各自擁有：武將紅度、動態、典藏、戰法、自訂戰法、隊伍。
- 換帳號不會把另一個帳號的隊伍帶過去。

至少會留一個帳號。刪除前請先匯出備份。

## 備份與還原

1. 打開**備份**。
2. **下載 JSON**，或全選文字複製，存到雲端硬碟、檔案 App 或另一台電腦。
3. 換手機或清掉網站資料之後，用**選擇檔案**或把 JSON 貼上，再按**從文字匯入**。
4. 確認帳號名稱後，選擇**取代並還原**。這會蓋掉這台裝置上目前的全部帳號。

備份檔包含所有帳號，不是只有正在看的那一個。單帳號檔是另一種 JSON（`kind` 為 `account`），請在帳號卡上載入；貼到備份頁不會整包取代。整包備份也不能在帳號卡上當成單帳號載入。舊版備份仍可匯入：主將會排到第一個位置，原本的主將與兩位副將不會對調。

## 怎麼用

**武將**只收名將（橙卡），列表一行一位，名稱是武將本名（孫尚香、陸遜、周瑜），不會在名字前面加「典藏」。勾選擁有後可展開紅度 0–5、動態、典藏；設定其中一項就會收合，並立刻寫進這台裝置。再點名稱可以展開改下一項。取消擁有也會收合。有動態形象或可標典藏的卡，才會出現「有／無」；內政武將不顯示典藏。把動態標成「有」之後，列上才會出現「動態」。把典藏標成「有」之後，列上才會出現「典藏」。篩選對齊遊戲裡常見的條件：品質、適性 A 以上、陣營、COST、軍事／內政、典藏、動態形象。預設依統御由高到低，同統御再依魏、蜀、吳、群；篩選之後仍是這個順序。也可以改成稀有、統御由低到高、陣營或名稱。新帳號的武將與戰法都是未擁有。已經上陣的卡會在名字下方標「部隊中」。自帶戰法有資料才顯示，沒有就不留空的「自帶戰法」。

**戰法**收已核對的 S 級與 A 級。這一頁只列出可勾選的傳承、事件、賽季商店，以及自己新增的非橙戰法。武將自帶寫在展開的武將列。每一列有等級標籤。列表先排 S，同等級再依類型、名稱。類型分頁：全部、指揮、主動、突擊、被動、兵種、陣法、內政。可搜尋名稱或說明。同一戰法同時只能裝在一個位置；裝上之後列表會變成灰色的**已佔用**，可配置從 `1/1` 變成 `0/1`。**事件**、**戰法傳承**是同一頁的篩選，選完之後版面跟全部戰法一樣，只列出該來源，勾選仍寫進這個帳號，不會消耗武將。更低階的戰法用「新增非橙戰法」手動加入。

**隊伍**可以有多支，各有名稱與備註。列表上的左右箭頭可調整順序，順序會寫進這個帳號，也會進備份。第一個位置是主將，後面兩位是副將。窄螢幕由上到下排，寬螢幕則由左到右。每位武將有兩個傳承槽。兵種適性排在名稱與統御的下一行，器械寫成「器」。卡片上會顯示紅度、動態與典藏，規則和武將列表一樣（紅 0、未開動態、未標典藏不顯示），這裡只能看，要改請回武將頁。編隊頁有「分享」，隊伍列表不放。一條連結只含那一隊的三人、傳承、兵書，以及這三人的紅度、動態、典藏，不會帶出其他隊伍。對方可以打開連結，或在隊伍頁貼上連結，再按「載入此隊伍」，才會把這一隊加進他當時選中的帳號，不會覆寫已經有的隊伍，也不會蓋掉整份備份。隊伍頁的「範本」另有一份配隊範本：下拉可篩劇本與國家，文字可過濾隊伍名稱或武將名稱，按「加入」才新增到目前帳號。載入後強度寫在隊伍名稱前面，加點寫進備註；圖鑑還沒收的戰法或兵書也留在備註。目前範本只有常規劇本。紅度、動態、典藏與武將有無直接套用，還沒擁有的武將會標記擁有，已經更高的不會被調低。缺戰法不會擋下整隊。確認頁和載入成功都會標「已套用」，缺少清單只列缺的戰法。選擇武將可依陣營、費用篩選，打開時依紅度排序（紅度加上動態與典藏各 1 分，高分在前）。搜尋框不會自動聚焦。點已選武將的名稱可打開同一個彈窗來替換該格，並標示即將替換的對象。點選一名武將或「這個位置留空」後，彈窗會立刻關閉並套用。空位仍用「選擇武將」。預設仍只列出已擁有。選傳承時預設只列出這個帳號已擁有的戰法，自帶戰法不在這份清單裡，也可以改看全部，並用類型與搜尋縮小範圍。搜尋框同樣不會自動聚焦。點已選戰法可再替換，彈窗會標示即將替換的戰法。選完或卸下後會立刻關閉並套用。兵書在跳出的面板裡依序選：體系（作戰、虛實、軍形、九變、始計、用間）→ 主兵書 → 兩個副兵書。副兵書不因未覺醒少一個，選滿兩個就關閉。主兵書和兩個副兵書都寫進隊伍，按鈕上只顯示體系、主兵書與副兵書。舊備份若只有一個副兵書，仍會讀成第一格。魏、蜀、吳、群的字用陣營色，武將卡左側色條保留。同名武將不能同時上陣。一隊只能有一個陣法。內政戰法只能配內政武將。這個版本沒有裝備，也沒有敵軍。

## 擴充圖鑑

圖鑑版本寫在 `data/meta.json` 的 `catalogVersion`（目前 1.2.6）。武將名冊是常見卡，**故意沒有收全**。戰法的戰鬥類 S 級收到兗州之戰的公開清冊，並補上已核對的後續事件戰法；A 級只收已核對類型的常用戰法，沒有把每張紫將都收進來。英雄命示的十二都尉以陣營「群」、標籤「都尉」收入，統御記 7（天賦身經百戰可 +1），適性暫以全 A 佔位。同賽季商店的拓本與精進陣法另列，來源標成「賽季」，不覆蓋原戰法。兵演春秋商店補了拓·蓄勢待發、拓·草船借箭、拓·刮骨療毒與精·靈機一動；拓·奪魂挾魄、拓·士別三日先前已收。自帶戰法只填了較確定的幾張，沒填的列上不顯示自帶那一行。`collection` 固定為 `false`：畫面上的典藏是帳號把典藏標成「有」（備份欄位 `awaken`），不是另一張卡，也不再跟動態綁在一起。改 `scripts/tactic-catalog.mjs` 後執行 `node scripts/build-catalog.mjs`，它會覆寫 `data` 底下的 JSON。

`data/generals.json` 一筆長這樣：

```json
{
  "id": "guanyu",
  "name": "關羽",
  "camp": "蜀",
  "cost": 7,
  "role": "軍事",
  "quality": "名將",
  "collection": false,
  "dynamic": true,
  "awaken": true,
  "apt": { "騎": "S", "盾": "A", "弓": "C", "槍": "S", "器械": "C" },
  "innate": "威震華夏",
  "nameKey": "關羽"
}
```

`dynamic: false` 表示沒有動態形象可解鎖，畫面上會隱藏「動態」。`awaken: false` 同樣會隱藏「典藏」。備份仍用這兩個欄位名。`nameKey` 用來擋同名上陣。`data/tactics.json` 用 `rank`（`S` 或 `A`）、`source`（`傳承`、`事件`、`賽季`、`自帶`）、`from`（武將 id）、`troops`（兵種限制，`null` 表示通用）。戰法頁的清單用 `傳承`、`事件`、`賽季`（賽季商店）與帳號自訂。`data/bingshu.json` 是六個兵書體系，每系有主兵書與副兵書。

三份 JSON 的 `catalogVersion` 請一起改。`scripts/build-catalog.mjs` 會**覆寫**這三份檔案，只有想整批重產時才執行 `node scripts/build-catalog.mjs`。

## 更新

App 版本寫在 `data/version.json`（目前 1.2.18，日期代碼 `20260929`）。帳號頁的「更新紀錄」和每頁底部的版本號都會讀這份檔案。`CHANGELOG.md` 是同一份清單。

每次發版都要一起改四件事：提高 `version`、把 `date` 改成 Asia/Taipei 的 `YYYYMMDD`、在 `releases` 最前面加上變更條目（並同步 `CHANGELOG.md`）、把 `sw.js` 的 `CACHE` 改成 `sgsz-planner-<version>`。

App 開著的時候如果 GitHub Pages 有新版本，上方會出現「有新版本可用」。點「重新載入」才會換上，不會自己重整。

確認方式：這版先開過一次，再依上面的步驟把版本與 `CACHE` 改掉並部署。回到這個分頁（或主畫面 App）就會看到提示；點下去之後提示消失，也不會一直重複跳出。

## 開發

靜態檔，沒有建置步驟。在這個資料夾執行：

```bash
python3 -m http.server 8765
```

然後打開 `http://127.0.0.1:8765/`。不要用 `file://`，否則圖鑑與離線快取不會載入。

```bash
npm test
```

檢查篩選、佔用、同名、備份格式與圖鑑是否對得起來。
